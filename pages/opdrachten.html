Sprint 0: Wie ben ik?

Tijdens de eerste twee weken van de minor web design en development moest ik mijzelf voorstellen door een website te maken wat bij mij past, waar mijn leerdoelen in mee zijn genomen en wat een passend gevoel uitstraalt. Daarnaast moest je jezelf uitdagen en net boven je comfort zone gaan coderen.

CSS to the rescue

Als volgt hadden we 4 weken de tijd om met alleen HTML en CSS een opdracht te maken.

De opdracht die ik had gekozen was: " Create an interactive CSS-only silly walk (or an interactive instruction for performing a silly walk)"

Tijdens dit vak kon ik goed aan mijn leerdoelen werken om een visueel css aantrekkelijke code te schrijven, hierbij heb ik geleerd hoe ik vormen moet maken met CSS, heb ik leren werken met ::before en ::after en ben ik erachter gekomen dat je toffe dingen kan doen met gradients.

Browser technologies

Tijdens de vier weken CSS hadden we ook browser technologies.

Opdracht: Op basis van de Erfbelastingaangifte formulier van de belastingdienst een interactief en toegankelijk web-formulier maken. Waarbij wij de power van HTML en CSS gebruiken. En dit doen aan de hand van progressive enhancement.

Dit vak heeft mij geholpen om te begrijpen wat daadwerkelijk de kracht is van html en dat het meer doet met toagenkelijkheid dan ik dacht.

Tijdens dit vak kon ik aan mijn leerdoel werken over javascript. Ik heb zelfstandig functions geschreven die ik ook begreep en aan andere kon uitleggen. Ik vind het wel nog lastig om gebruik te maken van de variabele en wanneer je die moet inzetten, maar daar zal ik bij een ander vak aan werken.
