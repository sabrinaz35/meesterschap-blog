# meesterschap-blog
Dit is een blog waarin ik laat zien wat ik afgelopen maanden heb gedaan bij de minor web design en development. Wekelijks hebben we een weekly nerd bijgewoond waar ik mijn bevindingen en interessante onderwerpen uit benoem. En de gemaakte opdrachten laat zien.

## Leerdoelen bij sprint 0
Tijdens deze minor heb ik verschillende leerdoelen voor mijzelf gesteld die luiden als volgt:
1.  Leren begrijpen hoe je een redelijke complexe function schrijft en goed begrijpen wat ik nu doe. Zodat ik zelfstandiger met javascript om kan gaan en ook makkelijker zelf dingen kan toevoegen.
2. Visueel aantrekkelijke css code schrijven, dingen uitproberen met svg's en meer de diepte opzoeken met animaties en de mogelijkheden daarvan. Zodat ik meer de ins en out en de mogelijkheden te leren kennen. Maar voornamelijk kijken naar wat er allemaal nog meer mogelijk is.
3. Tijdens het samenwerken mijn belangen beter benoemen en de andere daarin ook de ruimte in te geven. Zodat de communicatie in groepsverband beter en soepel kan laten lopen.



## Nieuwe leerdoelen
Tijdens de verschillende vakken heb ik al ontzettend veel geleerd, en heb ik mijn leerdoelen op verschillende manieren kunnnen toepassen. Alleen wil ik ze voordat ik aan de meesterproef begin toch wat fine tunen en aanpassen.
1. Aan het einde van de meesterproef wil ik duidelijkere code schrijven, zodat het overdraagbaar en makkelijk te bergijpen is voor een ander.
