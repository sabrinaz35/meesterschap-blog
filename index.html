Web design en development 2026

Leerdoelen voor meesterproef

  1. Tijdens het samenwerken wil ik mijn belangen beter benoemen en andere daarin ook de ruimte te geven. Daar bedoel ik mee meer mijn mening uitspreken. Zodat de communicatie in groepsverband beter voor iedereen prettig verloopt. Dit wil ik doen door vooraf duidelijke afspraken te maken, bijvoorbeeld over manier van communiceren en wie verantwoordelijk is voor de GitHub-merges.
  2. Aan het einde van de meesterproef wil ik duidelijkere en beter overdraagbare code schrijven. Vooral bij het schrijven van JavaSscript-code begrijp ik wel zelf wat ik doe, maar het is belangrijk dat andere het ook makkelijk kunnen begrijpen. Dit hangt samen met afspraak maken, maar ook een duidelijke naam geven aan de variabelen en het consistent plaatsen van de variabelen. En comments neerzetten.
  3. Daarnaast wil ik ook werken aan de visuele esthetiek van een website door passende en interessante features eraan toe te voegen. Een beetje de grens opzoeken van mijn kennis en tergelijkertijd werken aan mijn leerdoel van afgelopen weken: het schrijven van redelijk complexe JavaScript - en CSS- code die ik ook bergijp. Dit wil ik doen door binnen het meesterproefproject uitdagendere functionaliteiten op mij te nemen.

Werk waar ik het trotst op ben

Er zijn een aantal werken waar ik wel trots op ben en dat zijn de css en de API werken. Dat komt omdat ik daar bij beide vakken echt veel technische snufjes heb geleerd en heb weten toe te passen.

Daarnaast heb ik omtrent UX veel geleerd bij HCD en BT, omdat je op een andere manier naar een design leert kijken.

Interessantste weekly nerd

Een van de meest interessante en toffe weekly nerds vond ik wel Niels bij de web you want, omdat hij echt een web voor zichzelf maakt wat hij leuk en interessant vindt. Hij volgt zijn passie en zijn ideeën en ik denk dat ik daar nog veel uit kan halen betreft mijn eigen leerproces.

Daarnaast vond ik het leuk dat Rosa ook haar passie volgt en dat je met een oude pc bewijze van spreken een eigen server kan maken.

Reflectie

Na eerste gesprek

Ik ben het meeste trots op de animatie van de svg en hoe uiteindelijk de look van mijn boekje is geworden. Ik ben blij met wat ik neer heb kunnen zetten in zo'n korte tijd. Maar ik ben wel weer meteen achter een nieuw leerdoel gekomen en dat is. Vooraf een design maken en dan pas gaan werken aan de code, nu was ik namelijk nog best wel zoekende in hoe ik het eruit wilde laten zien. Ook heb ik nog moeite met javascript en heb daarom een van mijn leerdoelen daarvoor bedacht.

Ik ga in ieder geval nog verder werken aan mijn leerdoelen en mijzelf blijven uitdagen, maar dat moet binnen deze minor wel goedkomen.

Reflectie voor gesprek 2

Voor mijn idee is het sinds sprint 0 is het in een treinvaart voorbij gegaan. Ik heb sinds dat moment ook zoveel nieuwe dingen gemaakt en dat had ik totaal niet verwacht.

Tot nu toe gaat het allemaal goed, ik merk dat ik javascript ook steeds meer onder de knie krijg en ik merk dat ik daardoor ook zekerder ga voelen. Het blijft lastig, maar ik moet er gewoon consistent mee bezig zijn, anders zakt het weg.

Mijn grootste leermomenten zijn geweest bij css en api, voornamelijk omdat ik daar veel heb geleerd over wat er allemaal mogelijk is. Daarnaast kan ik de vakken als bt en hcd ook niet uitsluiten, omdat ik daar weer een nieuwe manier van denken heb geleerd. Ik heb bij die vakken rekening gehouden met de users en dat vraagt toch een andere manier van denken en meer stilstaan bij wat je aan het maken bent.

Javascript blijft nog wel lastig, maar het gaat wel steeds beter. Ook heb ik gemerkt dat bij sommige vakken ik een beeld in mijn hoofd had en van plan was dat op een bepaalde manier te doen, maar het totaal anders uitgepakt had. Daarom denk ik dat het belangrijk is voor mij om vooraf al stil te staan bij punten en gaan nadenken hoe ik dat kan doen in plaats van meteen beginnen.

Voor in de toekomst wil ik nog meer toffe dingen doen met css en javascript en dan voornamelijk op gebied van animaties dat vind ik leuk.
